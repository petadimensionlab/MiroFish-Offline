1. 概要

モデルと実験デザインを固定したうえで、ゲームの種類、ペルソナの集合、ネットワークのトポロジ、チャネル適合ダイアド、忘却つき記憶を順に変えて、LLM エージェント（gemma4:26b、思考あり）の行動を比べた。各条件は 8体または 16体 × 10期、1条件につき1ラン（seed 0）。ここから言えるのは「傾向の手がかり」までで、因果や有意差は主張しない。同じ条件の反復ラン（seed 1・2）は現在実行中で、結果は未着。

最初の2つの発見（位置バイアスとペア内チャット）は、本実験の設計（チャットなし、複数ゲーム、ネットワーク会話）がなぜそうなったかの根拠でもある。

主な発見

  1. 思考なしの 12b は先頭の選択肢を選ぶだけだった。 gemma4:12b（思考なし）は 160 回の決定すべてで先に提示された選択肢を選んだ（chat_12b 80/80、nochat_12b 80/80）。協力率はチャットの有無にかかわらず全期 0.50。思考ありの 26b では先頭の選択肢の割合が、チャットありで 40/80（0.50）、なしで 67/80（0.838）。
  2. ペア内チャットは協力を 1.00 に張り付かせる。 chat_26b は協力率が 10期とも 1.00。チャット 160 通すべてがゲームの話題で、宣言した意図は 80/80 守られた。チャットなし（nochat_26b）は 0.625 → 0.25（全期平均 0.412）、条件付き協力 0.806 / 0.073。研究の問いを測るため、本実験は chat_turns=0 を守る（NOTES #51）。
  3. 理論への近さはゲームごとに違う。 beauty は平均 20.06 → 0（全員 0 は第7期から）。ultimatum は 10/20 の折半が毎期、受諾率 1.00。trust は送金が 5.88 → 7.88（最大 9.12）、返金割合は 0.45 → 0.657。
  4. ペルソナの集合が結果を大きく変える。 公共財（pgg）は、一般人ペルソナで 0.984 → 1.00（nash_share 0）、職場ペルソナで 0.875 → 0.188（nash_share 0.537、個人内の条件付き協力の傾き +0.636）。
  5. ネットワーク会話は第1期の協力を上げる。持続はトポロジ次第。 第1期は対照 0.50、会話あり 0.625〜0.812。第10期は ER 0.562、WS 0.50、BA と ring は 0.312（対照と同じ）。
  6. チャネル適合は辺の使われ方を予測し、記憶つきの条件で協力が最も残った。 相性 A と辺ごとの会話の試行数の Spearman は 0.411（p=0.03、28辺）。94会話中 22 が未返信（実現返信率 0.766）。第10期の協力率は、忘却つき記憶の条件が 0.625 で、チャネル付き 4条件の最高（対照 0.188）。いずれも1ラン。

2. 狙いと目的

研究の問い

出発点は前回レポート（REPORT.md）と同じ、「言説 → 行動 → 言説」の閉ループである（plan.md §1〜3）。ここでは問いを次のように絞っている。ゲームの相手以外との言説が、相手との行動を変えるか。 相手と直接話せる条件では行動が合意で決まってしまい、言説の効果が測れないからである。

妥当性の条件は2つ。(1) まず人間で知られている規則性を再現できるか確かめる。(2) 選択肢の並びをランダムにして位置の影響を打ち消す。1つのゲームだけでは (1) を確かめにくいので、複数のゲームを使う。

前回から持ち越した課題

前回（qwen3:4b と gemma4:e4b の初期ラン、NOTES #1〜#46）の未解決点は次の4つ。

  • qwen3:4b が選択肢の文字 A を「協力的」と連想して選ぶ。
  • gemma4:e4b は記号の見た目で選び、相手が協力した後ほど裏切る逆向きの相互主義を示す。
  • SNS 上の議論は、ゲームの話にほとんどならない。
  • その結果、「言説が行動を変えた」証拠としては使えない（前回の結論）。

3.1 システムの変更点

  • 経路は変わらない: oTree の bot → bridge /api/experiment → step-server（OASIS）→ Ollama。
  • 意思決定プロンプトを v2 にした。「SNS の投稿ではない」「点数は実際の報酬」「記号に意味はない」「何を選ぶか理由と共に言う」を入れた（NOTES #48 より）。

  • モデルは3種を使った。gemma4:e4b（前回の続き。今回は部分ランのみ）、gemma4:12b（LLM_REASONING_EFFORT=none、思考なし）、gemma4:26b（MoE、思考あり。以降の主力。MODEL_TIMEOUT=600）。

  • 理解テストは全19ランで満点（comprehension）。欠測の決定は全19ランで 0。
  • oTree 側に設定だけ用意して今回は実行していない条件: pd_net_ba_chsel、pd_net_ba_chrep。

接触率の確認（負の二項）

接触率 λ は Gamma(形状 r=0.5、平均 μ=1) から引き、1期に自分が始める会話数は k ~ Poisson(λ)（混合で負の二項分布、分散 μ+μ²/r = 3.0）。この16体のサンプルでは λ の平均 0.7214、中央値 0.2918、最大 3.1545、λ<0.1 が 5/16体と右に裾が長い。ただし実際に引いた k（160 回）は平均 0.7875、分散 1.6527 で、理論の平均 1.0、分散 3.0 より小さい。16体の小標本であること、開始上限 3・負荷上限 4 で打ち切っていることが理由と考えられる。右に裾は長いが、理論ほど散らばっていない、というのが正直な見方である。

5. 考察

5.1 位置バイアスと思考の必要

qwen3 の文字 A、e4b の記号の見た目、12b の先頭 160/160 と、モデルが変わるたびに別の形で提示の仕方が行動を決めていた。思考ありの 26b でも先頭の選択肢の割合は残る。16体のランでは 0.669（net_er）〜0.912（net_off）で、対照の net_off が最も高い。位置の影響が残る分、協力率の水準と差は割り引いて読む必要がある。エージェントごとの並びのランダム化と、多数のセッションでの反復が対策になる。

5.2 ペルソナの枠組みは処置の一部

SNS の枠が後ろ向き帰納を抑える（NOTES #52）。職場ペルソナでは公共財が減衰した。さらに、チャネルの段落を足しただけで会話なしの対照が動いた: ch_off は 0.625 → 0.188、net_off は 0.50 → 0.312。ペルソナの文章は処置の一部であり、比較は同じペルソナの集合の中でしかできない。

5.3 推論型のゲームは人間より速く収束し、規範型のゲームは人間的だが均一

beauty は第1期 20.06、第7期以降 0 で、人間より速く均衡に着く（人間の第1期は約35、NOTES #53 より）。trust は返金割合が上昇し（0.45 → 0.657）、全額送金の人数が 2 → 7 に増える。ultimatum は全員が折半で、最小も最大も 10。人間的な傾向（公平・互恵）だが、個人差も拒否も出ない。均一さは LLM の特徴で、人間のデータの再現とは言えない。

5.4 会話は第1期を押し上げ、持続はトポロジ次第

第1期は、対照 0.50 に対し会話ありの4条件が 0.625〜0.812。第10期は ER 0.562、WS 0.50、BA と ring が 0.312（対照と同じ）。全期平均は ER 0.681、WS 0.531、ring 0.413、対照 0.375、BA 0.368。ER・WS で協力が残ったが、1ランずつで、1体 = 0.0625 の世界なので、順位を言える水準ではない。

5.5 BA ネットワーク

BA は次数の同類選択性が −0.565 と強い負で、最大次数 7（ハブ）がある。BA は条件付き協力のうち、相手が裏切った後の協力が 0.122 と、会話のある4つのネットワーク条件で最も高い（ER 0.091、ring 0.024、WS 0.015）。前期に協力し、前期に裏切った会話相手がいた者の 96%（26件）が協力を続けたのに対し、会話なしは 69%（16件）。前期に裏切った者は戻らなかった。会話には自分のペアの結果と意図の報告が多く、露骨な搾取の発言も含まれる。

5.6 記憶は協力を保つか

忘却つき記憶の条件は第10期 0.625、条件付き協力 0.968 / 0.020 で、チャネル付きの中では協力が最も保たれた。ただし ch_ba0（相性なし）も 0.562 で、差は 1体分に当たる。裏切りの言及を残した者の行動にも明確な違いは見えない。1ランなので、記憶が協力を支えると言う根拠にはならない。

5.7 妥当性への脅威

  • n=8/16、1 seed、LLM のサンプリングは seed 固定でない（再現しても同じ値にならない）。
  • ceiling 効果（チャットありで 1.00、NOTES #50）。
  • ペルソナの文章の影響（5.2）。
  • 指標の限界: on_topic は正規表現、partner_reports と possible_confusion は狭い表現、負の二項の確認は 16体の λ のサンプル（k_drawn の分散 1.6527 は理論の 3.0 より小さい）。
  • 取り違えの例が正規表現で拾えない（§4(e)）。
  • #55 の修正前は職場ペルソナの重複名（16体中 Elena V. が2人、Alex R. が2人）が区別されていなかった。トポロジの5ランは修正前（NOTES #56 D より）。
  • 信念調査の事後は、26b の PD ランと pgg_workplace で欠測（beliefs.post が null）。pgg_general では事後 6.625 がある。信念調査自体を行っていないランもある（beauty、trust、ultimatum）。
  • モデルは gemma4 系のみ。

5.8 人間の知見との関係

ここで挙げるのは一般的に知られた知見だけである。公共財の拠出の減衰と条件付き協力者の存在（Fehr & Gächter 2000、および Fischbacher・Gächter・Fehr の条件付き協力者の類型）、beauty contest で第1期に均衡より高い推測が出て 0 に近づくこと（Nagel 1995）、信頼ゲームで送金と返金が出ること（Berg et al. 1995）。この報告のデータは、これらと向きが合うゲーム（beauty、pgg 職場、trust）と、合わないゲーム（pgg 一般人）がある、というところまでしか言えない。
